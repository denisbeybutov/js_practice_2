В JavaScript (ES2019) уже есть метод Array.prototype.flat(), который уменьшает вложенность Array. Пожалуйста, реализуйте свой собственный метод.

  const arr = [1, [2], [3, [4]]];
  flat(arr)
  // [1, 2, 3, [4]]
  flat(arr, 1)
  // [1, 2, 3, [4]]
  flat(arr, 2)
  // [1, 2, 3, 4]
